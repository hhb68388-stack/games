# ركن الألعاب (غرف بالكود، بدون حساب)

ألعاب: مين برا السالفة، الروابط، أسرع كاتب. اللعب الجماعي عبر غرف بكود من 4 خانات.

## النشر على Railway
1. ارفع محتوى هذا المجلد إلى مستودع GitHub جديد.
2. في Railway: New Project ثم Deploy from GitHub repo واختر المستودع.
3. من Settings ثم Networking اضغط Generate Domain.
4. افتح الرابط وشاركه مع أصحابك.

تثبيت كتطبيق: افتح الرابط في الجوال ثم "تثبيت التطبيق" (أندرويد) أو مشاركة ثم "إضافة إلى الشاشة الرئيسية" (آيفون).

تشغيل محلي: `npm install` ثم `npm start`
